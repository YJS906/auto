# 네 조합 연속 주행 회귀: 미통과

전역 재측위 후속 시험이다. `summary.json`의 `completed=false`를 정확도 통과로 해석하면 안 된다.
전진 3초 후 RGB 2초 가림, 어느 한 조합이라도 ready=false이면 전 조합의 명령을 정지시키는 조건이다.

정지 지점에서 IPM의 최상위 두 후보 점수 차이가 약 2.29mm로 기본 4mm 기준보다 작았다.
IPM 두 조합이 미확정 상태로 대기했고, 재측위 대기 20초 한계로 recovery 구간에서 중단했다.
최종 RGB-D 두 조합은 TRACKING이었다. `phase_ready_fraction`에 출력 가용성을 기록했다.
중단 이후 좌우 원호·후진의 통과를 주장하지 않는다. 이 한계를 없애려고 점수 차이 기준을 낮추지 않았다.

`samples.json.gz`는 부분 오차·처리시간·상태 이력이다. 전역 초기화/강제 이동 성공 시험은
인접한 `2026-11-02-global*` 폴더와 별개이며 전체 트랙 재측위 보장이 아니다.
